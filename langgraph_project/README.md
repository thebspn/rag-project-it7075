# LangGraph Security Alert Triage Agent

This project implements an automated Tier-1 security alert triage agent using LangGraph to evaluate incoming endpoint, network, and cloud security alerts. The agent models triage decision logic using a shared state graph with deterministic nodes, conditional routing edges, and tool integration. Across an empirical benchmark of 12 custom security alerts (spanning Living-off-the-Land attacks, scheduled maintenance windows, and routine credential events), we evaluate the operational trade-off between missed security breaches and over-escalation alert fatigue. While purely widening keyword classification rules reduced missed incidents at the cost of high false-positive escalation rates, adding an automated change-management context verification node directly to the graph eliminated both error modes entirely—achieving a 100% catch rate without analyst fatigue.
